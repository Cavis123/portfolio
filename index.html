Sobre mí

Perfil técnico orientado a sistemas que tienen que funcionar todos los días.

Quién soy

Profesional IT enfocado en infraestructura, redes, automatización e IA aplicada. Me interesa construir soluciones que no dependan de una demo perfecta: tienen que ser operables, observables y sostenibles.

Trabajo desde la capa física y lógica de red hasta servicios web, APIs, scripts, paneles internos y asistentes basados en documentación propia.

Cómo trabajo

  • Primero arquitectura y alcance; después comandos, scripts y despliegue.
  • Documentación replicable para instalación, operación y recuperación.
  • Monitoreo, logs y alertas pensados desde el primer día.
  • Automatización progresiva: resolver lo repetitivo sin romper lo estable.

Casos de estudio

Proyectos resumidos con problema, solución y resultado esperado.

Infraestructura · IA local

Asistente interno con conocimiento propio

Implementación de una experiencia tipo ChatGPT en servidores propios, usando documentación interna como fuente de conocimiento y un panel web para administrar archivos y consultas.

Problema

Información dispersa, consultas repetidas y dependencia de personas clave para encontrar respuestas.

Solución

RAG sobre documentación interna, API backend, interfaz web y despliegue detrás de Nginx.

  • Debian
  • FastAPI
  • Ollama
  • SQLite
  • Nginx
Redes · Monitoreo

Segmentación y visibilidad de infraestructura

Diseño de topología, direccionamiento, VLANs y monitoreo para ordenar una red corporativa y detectar problemas antes de que escalen.

Problema

Baja visibilidad del tráfico, crecimiento desordenado y diagnóstico lento ante incidentes.

Solución

Separación lógica de servicios, documentación de red, métricas, dashboards y alertas proactivas.

  • VLANs
  • Routing
  • SNMP
  • Dashboards
  • Alertas
Automatización · Backend

Paneles web para procesos diarios

Desarrollo de interfaces internas para centralizar turnos, reportes y operaciones conectadas a bases de datos existentes.

Problema

Procesos manuales, archivos sueltos y falta de una vista única para operar o consultar información.

Solución

Paneles web livianos, formularios, reportes, conexión a base de datos y flujos más simples.

  • HTML
  • CSS
  • JavaScript
  • Python
  • MySQL
